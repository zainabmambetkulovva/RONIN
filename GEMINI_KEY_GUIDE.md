# 🔑 Как ПРАВИЛЬНО получить Gemini API Key

## ❌ Частая ошибка

Вы можете случайно получить **НЕПРАВИЛЬНЫЙ** ключ из Google Cloud Console (начинается с `AQ.` или другого префикса). Это **НЕ** Gemini API key!

## ✅ Правильный способ

### Шаг 1: Откройте правильную страницу
🔗 **https://aistudio.google.com/apikey**

**НЕ** используйте:
- ❌ https://console.cloud.google.com (это другие ключи!)
- ❌ Google AI Platform
- ❌ Vertex AI

### Шаг 2: Войдите в Google аккаунт
Используйте любой ваш Google аккаунт

### Шаг 3: Создайте API Key

Вы увидите страницу **"Get API key"**

Нажмите одну из кнопок:
- **"Create API key in new project"** (рекомендуется для новых)
- **"Create API key"** (если у вас уже есть проект)

### Шаг 4: Скопируйте ключ

API Key появится на экране. Он должен:
- ✅ Начинаться с `AIza`
- ✅ Быть длиной около 39 символов
- ✅ Содержать только буквы, цифры, дефисы, подчеркивания

**Пример правильного ключа:**
```
AIzaSyDaGmWKa4JsXZ-HjGw7_SzSb9uNmOe6789
```

**Примеры НЕПРАВИЛЬНЫХ ключей:**
```
AQ.Ab8RN6K...  ❌ (это OAuth token)
ya29.a0...     ❌ (это access token)
1234567890...  ❌ (это client ID)
```

### Шаг 5: Вставьте в .env файл

Откройте файл `ronin/.env` и замените строку:

```bash
GEMINI_API_KEY="AIzaSyDaGmWKa4JsXZ-HjGw7_SzSb9uNmOe6789"
```

**ВАЖНО**: 
- Уберите пробелы до и после ключа
- Ключ в кавычках
- Без точки с запятой в конце

### Шаг 6: Проверьте ключ

В терминале запустите:
```bash
cd ronin
node test-gemini.js
```

Должно появиться:
```
✅ SUCCESS! Gemini ответил: Привет
✅ API Key работает правильно!
```

Если ошибка - читайте сообщение, оно подскажет что не так.

### Шаг 7: Перезапустите сервер

**ОБЯЗАТЕЛЬНО** перезапустите сервер после изменения .env:

```bash
# Остановите (Ctrl+C)
# Затем запустите снова:
npm run dev
```

Изменения в .env файле **НЕ** применяются автоматически!

## Частые проблемы

### "API key not valid"
**Причины:**
- Ключ скопирован не полностью
- Есть пробелы в начале/конце
- Используется старый/удаленный ключ

**Решение:**
- Создайте НОВЫЙ ключ на https://aistudio.google.com/apikey
- Скопируйте заново
- Проверьте нет ли пробелов

### "Billing not enabled"
**Причина:** Нужно включить биллинг для проекта

**Решение:**
1. Откройте https://console.cloud.google.com/billing
2. Добавьте платежный метод (карту)
3. Gemini API имеет бесплатный уровень (60 запросов/минуту)

### "API not enabled"
**Причина:** Gemini API не активирован

**Решение:**
1. Откройте https://console.cloud.google.com/apis/library
2. Найдите "Generative Language API"
3. Нажмите "Enable"

### Сервер не видит новый ключ
**Причина:** Забыли перезапустить сервер

**Решение:**
1. Остановите сервер (Ctrl+C)
2. Запустите снова: `npm run dev`
3. .env читается только при старте!

## Альтернатива: Environment Variables

Если .env не работает, попробуйте установить напрямую:

**Windows (PowerShell):**
```powershell
$env:GEMINI_API_KEY="AIzaSy..."
npm run dev
```

**Mac/Linux (Terminal):**
```bash
export GEMINI_API_KEY="AIzaSy..."
npm run dev
```

# 🔧 Исправление ошибки регистрации

## Проблема
При регистрации выходит ошибка: **"Ошибка сервера"** 
Причина: База данных не синхронизирована с Prisma схемой.

## ✅ Решение

Откройте терминал в папке `ronin` и выполните:

```bash
npx prisma db push
```

Когда спросит "Do you want to ignore the warning(s)?", нажмите: **y** (Yes)

Готово! Регистрация теперь работает. ✅

4. Посмотрите логи сервера в терминале
